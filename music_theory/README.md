# 음악 이론 SFT 데이터셋 v2.2

Qwen3-VL의 음악 이론 개념과 계산 능력을 학습하는 영문 텍스트 데이터셋입니다.
팀 baseline의 `mmmu_pro_cot` 프롬프트를 사용하며, 응답은 설명 뒤 마지막 줄에 `Answer:`를 쓰는 형식입니다.

v2.2는 v2.1의 문항 수, 질문 내용, 선택지, 정답과 데이터 분리를 유지하고,
프롬프트, 응답 순서와 학습 후 평가 경로를 baseline에 맞춘 버전입니다.
제작 방식과 논문 근거는 [RESEARCH.md](04_문서/RESEARCH.md), 실행 명령은 [PIPELINE.md](04_문서/PIPELINE.md)에 있습니다.

## baseline 적용 기준

| 항목 | 적용 내용 |
| --- | --- |
| 기본모델 | `Qwen/Qwen3-VL-4B-Instruct` |
| 기본모델 revision | `ebb281ec70b05090aa6165b016eac8ec08e71b17` |
| 입력 | baseline `mmmu_pro_cot`의 user 지시와 Qwen chat template |
| 학습 정답 | 설명 뒤 마지막 줄의 `Answer:` |
| 학습 환경 | Transformers 4.57.1, PEFT 0.17.1 |
| 평가 환경 | vLLM 0.27.1, Transformers 5.5.3 이상 |
| 생성 조건 | temperature 0.7, top_p 0.8, top_k 20, repetition_penalty 1.0, presence_penalty 1.5, seed 42 |
| 길이 한도 | 최대 생성 32,768토큰, 평가 서버 문맥 40,960토큰 |
| 평가 정밀도 | bfloat16 |
| 채점 | 기존 baseline 규칙 파서, 추출 실패 시 동일 judge |

학습과 평가는 서로 다른 conda 환경에서 실행합니다. 두 requirements를 같은 환경에 설치하지 않습니다.
평가 코드는 저장소의 `baseline/` 구현을 재사용하므로 `MMDL/baseline/`과 `MMDL/music_theory/` 구조를 유지합니다.
기존 평가 기준과 실행 옵션은 [baseline 실행 안내](../baseline/README_mmmu_eval.md)에 있습니다.

## 데이터 구성

| 영역 | 학습 | 개발 | 최종 평가 |
| --- | ---: | ---: | ---: |
| 음정 판별, 이조 | 720 | 72 | 72 |
| 음계, 선법, 음계도수 | 390 | 39 | 39 |
| 화음 구성, 종류, 전위 | 480 | 48 | 48 |
| 리듬 길이, 마디 완성, 템포 계산 | 750 | 75 | 75 |
| 로마숫자 분석, 종지 | 450 | 45 | 45 |
| 개념 정의, 개념 구별, 오개념 수정 | 210 | 21 | 21 |
| 합계 | 3,000 | 300 | 300 |

학습셋은 객관식 1,500문항과 단답형 1,500문항입니다.
개발셋과 최종 평가셋은 각각 300문항의 4지선다이며, 정답 위치 A/B/C/D를 75문항씩 배분했습니다.
서양 조성음악과 12평균율을 기준으로 음이름 철자와 옥타브를 구분합니다.

## 실행 흐름

1. 문항 검수와 데이터 검증 결과를 확인합니다.
2. 평가 환경에서 원본 baseline의 개발셋 결과를 생성합니다.
3. 학습 환경에서 학습 3,000문항과 개발 손실용 300문항으로 LoRA를 학습합니다.
4. 같은 학습 환경에서 LoRA를 고정 revision 원본에 병합합니다.
5. 평가 환경에서 병합 모델을 같은 조건으로 평가하고 개발 결과를 비교합니다.
6. 설정 확정 후 최종 평가 300문항과 기존 MMMU Music 및 전체 900문항을 평가합니다.

학습 길이 1,536은 학습 샘플의 입력과 응답을 합친 한도입니다.
평가의 `max_new_tokens=32768`, `max_model_len=40960`과는 용도가 다릅니다.

## 검증과 실행 기록

데이터의 정답 계산, 문제군 분리, 공개 평가 텍스트 중복, tokenizer와 assistant 손실 마스킹을 검사합니다.
baseline 프롬프트, 요청 값, 규칙 파서와 judge 연결은 코드 및 모의 HTTP 평가로 점검합니다.
실제 GPU 학습과 성능 향상 결과는 실행 후 생성되는 학습 및 평가 manifest로 기록합니다.
음악 전공자의 문항 검수 이력은 `03_기타/검수자료/human_review.json`에 작성합니다.
