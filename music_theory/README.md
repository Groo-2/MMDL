# 음악 이론 SFT 데이터셋 v2.1

Qwen3-VL의 음악 이론 개념과 계산 능력을 학습하는 텍스트 데이터셋입니다.
영문 자연어 질문과 음이름을 입력하고, 정답과 짧은 설명을 출력하도록 구성했습니다.

처음 참여하는 팀원은 [프로젝트 설명과 연구 근거](04_문서/RESEARCH.md)를 먼저 읽어주세요.
목적, 제작 방식, 참고 논문, 데이터 분리와 평가 절차를 한 문서에 정리했습니다.

## 폴더 안내

| 폴더 | 들어 있는 내용 |
| --- | --- |
| `01_학습용/` | 학습 코드, 학습 3,000문항, 개발 300문항, 설치 목록 |
| `02_평가용/` | 답변 생성과 채점 코드, 평가 문항과 정답, 최종 평가 검수 자료 |
| `03_기타/` | 데이터 생성과 검증 도구, 검증 기록, 학습 문항 검수 자료 |
| `04_문서/` | 실행 순서, 논문 근거, 빠른 파일 안내 |

실행할 때는 이 폴더 구조를 유지하세요. 자세한 명령은 `04_문서/PIPELINE.md`에 있습니다.

## 데이터 구성

| 영역 | 학습 | 개발 | 최종 평가 |
| --- | ---: | ---: | ---: |
| 음정 판별, 이조 | 720 | 72 | 72 |
| 음계, 선법, 음계도수 | 390 | 39 | 39 |
| 화음 구성, 종류, 전위 | 480 | 48 | 48 |
| 리듬 길이, 마디 완성, 템포 계산 | 750 | 75 | 75 |
| 로마숫자 분석, 종지 | 450 | 45 | 45 |
| 개념 정의, 개념 구별, 오개념 수정 | 210 | 21 | 21 |
| 합계 | 3,000 | 300 | 300 |

학습셋은 객관식 1,500문항과 단답형 1,500문항입니다. 개발셋과 최종 평가셋은
각각 300문항의 4지선다이며, 정답 위치 A/B/C/D를 각각 75개씩 배분했습니다.

서양 조성음악과 12평균율을 기준으로 음이름 철자와 옥타브를 구분합니다.
단순음정과 복합음정, 9개 음계/선법, 9개 화음 종류를 다룹니다.
종지는 근음 위치로 제시된 마지막 두 화음의 진행을 기준으로 판별합니다.

## 사용 및 공유

1. 학습 담당자는 `train.jsonl`로 학습하고 `dev_loss.jsonl`과 개발셋 결과로 설정을 선택합니다.
2. 설정을 확정한 뒤 평가 담당자가 최종 평가 300문항으로 학습 전후 성능을 비교합니다.
3. 학습 담당자에게는 `music_theory_text_v2_training.zip`, 평가 담당자에게는
   `music_theory_text_v2_evaluation.zip`을 전달합니다. 전체 파이프라인은 관리자가 보관합니다.

답변 형식은 `Answer: ...`와 한두 문장의 설명입니다. 객관식 채점은 정답 줄을 기준으로 합니다.

## 제작 및 검증

- 이론 규칙으로 새 문항과 정답을 생성하고, 계산 문항을 music21으로 재검산했습니다.
- 같은 문제의 역질문, 옥타브 변형, 화음 구성과 전위, 음계도수, 리듬 변형은 문제군별로 분리했습니다.
- MusicTheoryBench, MMMU Music, MMMU-Pro, SSMR-Bench, pilot20의 평가 텍스트와 중복을 검사했습니다.
- Qwen3-VL 토크나이저로 입력 길이와 답변 부분의 학습 처리를 확인했습니다.

현재 상태: 자동 검증 완료, 음악 전공자 검수 대기, GPU 학습 실험 대기.
